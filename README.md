

\# AuthenticationLab



\## Описание проекта



Приложение демонстрирует работу различных способов аутентификации пользователя.



\## Используемые способы аутентификации



\- Проверка логина и пароля.

\- Проверка отпечатка пальца.

\- Проверка QR-кода.

\- Проверка токена.



\## Дополнительные возможности



\- Ведение журнала работы приложения.

\- Сохранение результатов аутентификации в JSON.

\- Подсчёт успешных и неуспешных попыток.

\- Вычисление процента успешных попыток.



\## Технологии



\- C#

\- .NET Framework 4.8

\- Newtonsoft.Json

\- Serilog

\- xUnit



\## Тестирование



Проект содержит модульные тесты для проверки корректной и некорректной аутентификации.
