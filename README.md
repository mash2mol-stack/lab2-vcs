## 

## \- C#

## \- Serilog

## \- Newtonsoft.Json

## \- xUnit



\## Установка и запуск



\### Требования

\- Windows 10 или Windows 11.

\- Visual Studio 2022.

\- .NET Framework 4.8.



\### Порядок запуска

1\. Клонируйте репозиторий.

2\. Откройте решение AuthenticationLab.slnx в Visual Studio.

3\. Восстановите необходимые NuGet-пакеты.

4\. Выполните сборку решения.

5\. Запустите проект AuthenticationLab.
